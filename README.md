# ПОСЛЕДНИЙ СВЕТ (last-light)
Терминальная пошаговая выживалка-стратегия в постапокалипсисе.
Электричество кончилось вместе с миром. У тебя один генератор, трое выживших
и пепел за дверью. Другие убежища не ждут — они качаются прямо сейчас.
